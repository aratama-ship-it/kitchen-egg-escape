# 厨房脱出：卵が5区画を抜けるまで

**公開URL: https://aratama-ship-it.github.io/kitchen-egg-escape/** （スマホで開ける）

床すれすれの後方視点で、黄身を偏らせて卵を転がし、厨房の裏口を目指すブラウザゲーム。
1区画を30〜45秒で抜け、5区画で終わる。割れたら、その区画の最初からやり直す。

## 起動

```sh
npm install
npm run dev
```

表示されたURL（既定では `http://localhost:5173/`）を開く。

## 操作

- スマホ：一指でドラッグして保持する
- PC：マウスでドラッグして保持する
- PC補助：矢印キーまたは WASD
- `R`：いまの区画を最初からやり直す
- `Enter`：区画を抜けた画面から次へ進む
- 開発サーバーのみ `B`：破壊演出を即時確認する
- 開発サーバーのみ `N`：いまの区画を即クリアする
- 開発サーバーのみ `?stage=3`：3区画目から開く

ドラッグ方向へ黄身の内部質量が移動する。入力を離すと黄身は遅れて戻り、殻はその時点の速度と角速度を保ちながら、床との接触・摩擦で減速する。

**弱いドラッグでは動かない。** 実測では入力の強さが約0.55を下回ると卵は転がり出せない。
これは仕様であり、はっきり倒すことを求める操作になっている。

## 5つの区画

| # | 名前 | 長さ | 中心にある一つのこと |
|---|---|---|---|
| 1 | 仕込み台の下 | 4.0 m | まっすぐ転がす。寸胴と木箱をよける |
| 2 | 洗い場 | 4.6 m | 濡れた床（摩擦0.13）。止まれない・曲がれない |
| 3 | 配膳通路 | 5.0 m | 横切る配膳カート。壁ぎわで待ち、通り過ぎた側から渡る |
| 4 | 火口の前 | 4.6 m | 換気扇の横風。放っておくと熱い脚の側へ流される |
| 5 | 裏口 | 3.6 m | 扉の下の隙間は通路の八分の一。速さより正確さ |

区画の定義は [src/stages.js](./src/stages.js) にデータとして置いてある。
床の摩擦帯、障害物、動くもの、風、空気の色はすべてここで決まる。
`src/stage-builder.js` はその定義から描画と剛体を組み立てるだけで、
区画ごとの特別扱いはしていない。

## 現在の物理モデル

- Rapierの3D剛体を120 Hzの固定刻みで計算
- 高さ64 mm、最大幅約47 mmの卵形を、描画形状と590点の凸包コライダーで共有
- 殻8 g、黄身52 g、合計60 g
- 卵は**横倒し**で置く。立てて置くと、倒れたあと長軸が進行方向を向いて転がらなくなる
- 重力、接触、摩擦、反発、慣性、連続衝突判定を物理エンジンで計算
- 黄身はばね・減衰を持つ「移動する内部質量」とし、毎ステップ合成重心と慣性へ反映
- 殻に約1.8%の微小な非対称を持たせ、横ずれを任意の蛇行スクリプトではなく接触形状から発生させる
- 床以外への一定以上の衝突を接触力イベントで検出し、殻を破壊する
- 巡航速度は実測で約0.13 m/s。区画の長さはこの速度から決めている

詳しい前提と、実測で分かったことは [PHYSICS_MODEL.md](./PHYSICS_MODEL.md) を参照。

## 割れる演出

障害物へ強く衝突すると、短い閃光と乾いた音の後、殻片が床へ落ち、白身と黄身がその場に残る。
結果表示は約1.5秒待ってから「割れた。」「厨房は、止まらない。」だけを出し、派手な失敗演出にしない。

通常の床接触や、ごく弱く壁をこする動きでは割れない。現在の判定値はゲーム用の初期調整で、
実物の殻強度を測定した値ではない。

## 公開

`main` へpushすると GitHub Actions がテストとビルドを走らせ、GitHub Pages へ配信する
（`.github/workflows/deploy.yml`）。テストが落ちると公開されない。

避けるため `~/git-repos/kitchen-egg-escape` へ退避してある（`--separate-git-dir`）。
**このMac以外からは git 操作ができない。** iCloudが作る `〇〇 2.js` のような競合コピーは
`.gitignore` で公開対象から外している（消してはいない）。

## テスト

```sh
npm test
npm run build
```

29本。卵形状、黄身のばね・慣性・制御則、破壊判定に加えて、区画については次を確認する。

- すべての区画で床が隙間なく敷かれ、通り抜けられる幅が残っている
- **素直に操作したとき、5区画すべてを実際に完走できる**（Rapierで通しで転がして確認）
- 卵はどの区画でも横倒しで床の上から始まる
- 濡れた床では、入力を切ったあとの惰走が乾いた床より長い
- 換気扇の風が、火口のある側へ卵を引く
- カートは開始時に通路の中央を塞がず、壁ぎわに待避場所が残る

通過確認は `tests/stage-traverse.test.js` の操作モデルが行う。
これは「うまい人」ではなく「素直に隙間を狙うだけの人」を模しており、
ここで通れない区画は設計として通れないものとして扱う。

旧Canvas試作の `game.js` と `physics.js` は比較用として残しているが、
現在の `index.html` からは読み込まれない。

## 既知の課題

- 卵が障害物の角に噛むと、同じ方向へ入力し続けるかぎり抜け出せない。
  指を左右に振れば抜けられるが、初見では「詰んだ」と読まれる恐れがある。
- 実物の卵を転がした映像・計測値とのキャリブレーションはまだ行っていない。
- 音は割れる音と区画通過の二音のみ。BGM・環境音はない。
